# 代码质量白名单 —— 语法(与 hx-code-quality 模板一致).
#
#   <path>|<N>        行数豁免,**必须带登记上限 N**(挂上之后长过 N 依然红)
#   <path>::<func>    只豁免这一个函数(函数长度 / JSDoc 债务)
#   dir:<path>        目录文件数豁免
#
# 两条铁律:
#   1. 双向校验 —— 一次都没拦下违规的条目 = 陈旧条目 → 门禁直接 FAIL,必须删.
#   2. 粒度尽可能细 —— 豁免一条违规是还债,豁免一个文件是又签一张空白支票.
#
# 本仓**刻意保持为空**:用户明确要求体量/目录红线全仓生效,因此不靠白名单
# 接纳存量,而靠 .gates/*-baseline.json 的棘轮(只许降不许涨).
