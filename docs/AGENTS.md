# docs/AGENTS.md -- 文档约定

> 只讲[写 docs/ 时才知道的事]. 通用约定见根 [AGENTS.md](../AGENTS.md).

## 分类(硬性)
**文档总入口 = [README.md](./README.md)**, 里面有完整分类表 + 三条硬约定 + 真源地图.
新增文档**必须**在 `README.md` 登记(文档门禁会核对), 否则门禁 fail.

| 目录 | 放什么 |
|---|---|
| `guide/` | 使用指引(面向[怎么用]) |
| `design/` | 设计说明(面向[为什么这样设计]) |
| `reverse/` | 逆向结论(**实测**得到的上游事实, 编号文件) |
| `quality/` | 质量体系(门禁/红线) |
| `research/` | 调研报告 |

## 三条硬约定
1. **实测优先**: `reverse/` 里的结论必须来自实测(远程日志 / 直连回执 / 单变量对照), 不得只凭源码
   推断. 本仓已多次出现"源码看起来该如此, 实测相反" ---- 结论要写清证据来源.
2. **真源不重复**: 同一事实只在一处定义, 其它地方**链接过去**. 尤其模型名映射, 上游端点白名单这类
   有唯一真源的, 不要在文档里再抄一份.
3. **不写上游仓库路径形态**: 引用上游产物(如官方客户端 bundle)的文件名时, 写成叙述,
   不要写成仓库相对路径的形态 ---- 文档门禁会把后者当成[本仓文件不存在]而 fail.
